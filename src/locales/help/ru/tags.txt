[bold]:? tags — запросы к базе и ссылки[/bold]

  ?          - Запрос к базе (? теги, ?<tag>, ?? с группировкой; ?? показывает скрытые теги)
               Ввод `?` показывает теги с подсказкой (число команд + комментарий тега):
               буквы фильтруют, Tab/Enter вставляют `?tag` (Enter ещё раз выполняет),
               клик по строке выполняет запрос сразу. `??` оставляется как есть.
               ?text (2+ символа, такого тега нет) = поиск команд/комментариев по всем
               тегам; строки: <id> tag[tid]; Esc → ввод, затем Enter выполняет через !ID
               В ?? клик по тегу → вставить `!tag ` / `!tag[tid] ` в позицию курсора
               (строку не заменяет; terminal_mouse). Ctrl+клик или двойной клик по
               `!tag[tid]` вставляет и сразу выполняет (ровно как набрать ссылку и
               дважды нажать Enter; `!tag ` без tid только вставляется). Esc → ввод,
               затем Enter.
  !tag / !tag[tid] - Введите ! для списка тегов [file, kube, log]; Tab выбирает тег
               Затем команды показываются как `<id> tag[tid]  полная команда`; Tab вставляет `!tag[tid]`
               Собирайте пайпы/сохранения: `#file !file[1] | !file[2]` (предпросмотр раскрывает ссылки)
  !N         - Выполнить команду по ID из последнего запроса
