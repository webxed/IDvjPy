[bold]:? kctx — журнал кластеров[/bold]

  :kctx         - Журнал кластеров (kctx.json): список кластеров; переменные из
                `kctx_vars` в settings.yml сохраняются по кластеру, если заданы
                после логина. По умолчанию — встроенный стек: kubectl (NS POD
                DEPLOY SVC ING APP CTR QUOTA) плюс helm (RELEASE CHART VALUES);
                порядок имён — порядок в списках :kctx. `kctx_vars: []` выключает
                журнал, и `:kctx` сообщает об этом
  :kctx <cluster> - Войти (klogin <c> || kubectl config use-context <c>) и показать
                ранее использованные наборы переменных этого кластера; ровно с
                одним сохранённым набором он применяется сразу (выбирать не из чего).
                Логин выполняется БЕЗ command_timeout (tsh ходит в сеть; зависший
                логин виден в блоке и останавливается через F4 / :kill)
  :kctx <cluster> N - Войти и применить сохранённый набор N
  :kctx N       - Применить набор N из последнего показанного списка (:kctx N меняет только переменные)
