[bold]:llm — LLM-провайдеры[/bold]

  Конфиг — llm_providers.yml в каталоге данных (пример: src/llm_providers/ru.yml;
  при первом старте шаблон разворачивается сам). Провайдер по умолчанию — `default:`.

  :llm          - Список LLM-провайдеров из llm_providers.yml (пример в src/)
               Пока ответ в пути, блок крутит `⠋ thinking… 3s / 60s`
               (второе число = таймаут провайдера), так что медленный вызов — не зависание
  :llm offline <message> - Встроенная офлайн-заглушка (mock: без сети, без ключа);
                есть в любом конфиге, пока вы не определите свой `offline:`
  :llm <provider> <message> - Спросить указанный LLM через его API (заголовки/тело
                из конфига; секреты берутся из окружения, например $DEEPSEEK_API_KEY)
  :llm <message> - Спросить провайдера по умолчанию (`default:` в llm_providers.yml)
                $OUT — последняя непустая строка сфокусированного/последнего CommandBlock
                $BLOCK — полный stdout этого блока (также ${OUT} / ${BLOCK})
                @file — прикрепить текстовый файл (UTF-8, ≤200 КБ; несколько: @a.py @b.log;
                литеральный @ — @@). Лимит размера: ключ провайдера max_attachment_bytes
                Контекст: ключ провайдера history_turns: N хранит последние N пар
                user/assistant в памяти на эту сессию; :llm reset [<provider>|*] очищает его
                Плейсхолдеры: %MSG% (JSON-safe), %MSG_RAW%, %SYSTEM%, %MODEL%, %HISTORY%
                Tab дополняет имена провайдеров и `ask` после `:llm `
                Прокси 407: задайте $PROXY_USER / $PROXY_PASS (как в :update)
                Ответы — markdown и выводятся отформатированными (`llm_render_markdown:
                true`; простой текст всё равно то, что копируют F3/|/$BLOCK/:w).
  :llm ask <task> - Задача + шпаргалка по приложению + сохранённая библиотека
                тегов уходят провайдеру, поэтому ответ может быть готовыми
                ссылками вроде `!kpod[1]` или `!! kpod[1] && klog[1]`.
                Предлагаются только существующие tag[tid] (добавляется
                кликабельная строка ссылок; для клика нужен terminal_mouse).
  :llm ask <provider> <task> - То же, но спросить этого провайдера вместо
                провайдера по умолчанию (`default:` в llm_providers.yml).
                Тот же контекст для простого `:llm` с ключом провайдера
                app_context: true|N (N = бюджет символов; нет/false = выкл).

[bold]:cht — шпаргалки cheat.sh[/bold]

  :cht <query>  - Шпаргалки cheat.sh (cht.sh) в журнале: `:cht tar`,
                `:cht python read file` (пробелы → +), `:cht ~snapshot` (поиск),
                `:cht go/:learn` / `:list` (специальные страницы). Опции после `?`:
                `Q` без комментариев, `T` без цветов (по умолчанию `?T`). Базовый
                URL и опции — `cheat_sh_url` / `cheat_sh_options` в settings.yml.
                Вывод — обычный блок ($OUT, |, F3, F7, поиск).
