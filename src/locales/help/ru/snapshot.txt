[bold]:? snapshot — ограниченные снимки вывода[/bold]

  :snapshot list          Список сохранённых снимков
  :snapshot save NAME     Сохранить stdout сфокусированного или последнего блока
  :snapshot show NAME     Показать сохранённый stdout
  :snapshot diff NAME     Сравнить сохранённый stdout с текущим блоком
  :snapshot rm NAME       Удалить снимок

  Снимки хранятся в output_snapshots.json в каталоге данных приложения — отдельно
  от SQLite-библиотеки тегов и истории команд. Файл приватный (0600), записывается
  атомарно и ограничен 5 МиБ; хранится не более 20 снимков, каждый — до 256 КиБ.
  Повторное сохранение имени заменяет снимок.

  Сохраняется только stdout, замаскированный секретами на момент записи. stderr,
  текст команды, переменные окружения и содержимое vault не включаются. Слишком
  большой вывод обрезается по границе UTF-8. Это инструмент локального сравнения,
  не журнал аудита и не резервная копия вывода.

  `:diff` по-прежнему сравнивает два блока, которые ещё находятся в журнале.
