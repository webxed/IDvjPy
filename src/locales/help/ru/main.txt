[bold]IDvjPy_term VER - Справка по командам[/bold]

[bold]Команды приложения (префикс :)[/bold]
  Введите `:`, чтобы увидеть список всех команд с однострочной подсказкой
  (буквы фильтруют список, Tab/Enter вставляют команду; Enter ещё раз выполняет).
  Клик по имени ниже вставляет вызов во ввод — ничего не запускается.
  `:/text` — поиск по журналу.
  Группы команд подробно разобраны в темах — `:? <тема>` (список в разделе «Темы справки»).
  :? [тема]   - Показать эту справку; `:? llm`, `:? tags`, `:? calc` … — полный разбор темы
  :q          - Выйти из приложения
  :w <file>   - Записать вывод в файл
  :h [N]      - Последние N строк history_<instance>.txt (по умолчанию: 20)
                Вызовы команд-запросов (`:llm`, `:cht`, `:rg`, `:md`, `:run`,
                `:send`) остаются там для ↑/`:h`, но никогда не подсказываются —
                список — `history_queries` в settings.yml (пусто — не записывать).
                Опечатка (`command not found`, 127) убирается из файла и из ↑ —
                `history_forget_not_found: false` оставляет её
  :h /text    - Поиск по этому файлу в подсказках (уникальные строки, новые сверху); Enter выдаёт блок
  :h compact  - Уникальная старая история; последние history_keep строк остаются последовательностью
  :h import [shell] - Дописать историю оболочки (bash/zsh/fish/ksh/nu/pwsh или база
                atuin; `$HISTFILE` первым; пути под Linux/macOS/Windows) в
                history_<instance>.txt — ↑, `:h /текст` и подсказки видят её сразу.
                Последние 5000 строк/команд источника; ничего не выполняется.
                Без имени — все найденные источники.
  :c          - Очистить все блоки вывода
  :json       - Открыть JSON-просмотрщик (из последнего блока)
  :json <file>- Открыть JSON-файл в просмотрщике
  :md <file|path>[#L<n>] - Markdown-справочник с форматированием, `#L<n>` — на строку n; документы (docx/pdf/…) конвертируются (:? md)
  :rg <pat> [dir] - Поиск regex по markdown-файлам, результаты кликабельны (:? md)
  :i          - Анализатор Kubernetes Ingress (:i — команды, :? i — подробно)
  :cd [path]  - Показать или сменить cwd shell (БД тегов / история остаются в каталоге запуска)
  :fm [path]  - Открыть файловый менеджер ОС в новом окне (cwd или path)
  :term [path] - Открыть системный терминал в новом окне (cwd или path)
                $FILEMAN / $TERMINAL переопределяют системные по умолчанию
  :ed [<file>|$OUT|$BLOCK] - Открыть файл (или последнюю строку блока / полный
                stdout / пустой буфер) во внешнем редакторе; на время работы TUI
                приостанавливается. Редактор: `editor:` в settings.yml, иначе
                $VISUAL / $EDITOR, иначе sensible-editor / nano / vi. Файл на
                диске правится на месте. Для $OUT/$BLOCK/пустого буфера:
                однострочный результат попадает во ввод (Enter выполняет его);
                многострочный сохраняется по напечатанному временному пути
                (годится для `@file` / `| cmd`). `$VAR` и ленивый `$OUT`
                подставляются в путь (например, `:ed $TMPDIR/pod-$OUT.json`);
                нерешённый `$NAME` — явная ошибка, а не файл с именем `$NAME`.
  :env        - Перечитать .bashrc_term* (и алиасы ~/.bashrc) в этот процесс
  :session    - Показать или сменить экземпляр приложения (БД тегов общая; :? session)
  :new [NAME|-] [DIR] - Ещё один экземпляр в НОВОМ окне терминала (Ctrl+N; :? session)
  :send <session|*> <cmd> - Переслать команду в другую сессию (`:send!` — сразу;
                секреты — по имени, значение — в хранилище цели; :? send)
  :scope [add|rm|clear] … - Область видимости тегов ЭТОГО окна: `:scope add git`
                оставит набор git, `:scope rm k8s` — скроет его, `:scope clear`
                (или `:scope all`) — покажет всё снова. Фильтрует списки и
                подсказки (`?`, `??`, `?text`, `!`/Tab, лента заставки); явные
                адреса (`?tag`, `!tag[tid]`, `:run`, `:stats`, `:export`) работают
                как раньше — сохранённые цепочки не ломаются. Имя — группа
                хендбука (linux, k8s, git, …) или отдельный тег. Своё у каждой
                сессии: scope_<сессия>.json; маркер — в заголовке окна
                (`IDvjPy_term · git · only git`). Подробнее: :? tags
  :welcome      - Каталог сидов (как приветствие при пустой БД; клик --seed / .md)
  :backup       - Скопировать БД команд в backups/ (тот же снимок, что у --seed)
  :screensaver  - Оверлей простоя: матричный цифровой дождь (screensaver_matrix,
                по умолчанию) или звёздное поле в стиле NC; тикер во всю ширину;
                справка внизу слева; load/mem внизу справа. `:screensaver matrix`
                / `:screensaver stars` выбирают холст разово; `:screensaver 0` /
                `120` задают секунды простоя (screensaver_idle); клавиши/клики/
                скролл/движение мыши сбрасывают его, пересланный :send будит его,
                а сессия с настоящим TTY (`> cmd`, Ctrl+O, `:ed`) заново запускает
                отсчёт простоя — оверлей не встречает вас при возврате
  :r          - Поместить команду сфокусированного (или последнего) блока во ввод
  :r N        - Поместить команду N блоков назад во ввод (0 = последний)
  :cmd [N] [show] - Материализовать команду блока с текущими значениями $VAR
                (включая секреты) и скопировать её в буфер обмена; `show` ещё и
                печатает её (секреты становятся видимы). N = блоков назад (0 = последний).
  :log [N]    - Полный вывод блока в прокручиваемом Line-API просмотрщике (без
                лимита в 300 строк; строки — ↑/↓, страницы — PgUp/PgDn, Esc или q
                закрывают). Поиск через `/`; Enter — искать, n/N — следующее/
                предыдущее совпадение, Esc — закрыть поле поиска. Совпавшая строка
                выделяется целиком (акцентный фон + bold). `f` — только совпавшие
                строки (снова `f` / Esc — назад ко всем строкам; нужен
                предварительный поиск; подзаголовок сохраняет исходный номер
                строки), и тогда по совпадениям ходят стрелки ↑/↓, а не скролл.
                Enter / Ctrl+C копируют выделенную (подсвеченную) строку в буфер
                (как Enter в построчном режиме F2; без поиска выделять нечего —
                просмотрщик говорит об этом, а не копирует первую строку).
                N = блоков назад (0 = сфокусированный/последний).
                Показывает stdout блока (как F3), escape-коды снимаются. Также
                F7. `y` копирует путь исходного файла (сырой вид `:md`)
  :kill [all] - Остановить выполняющуюся фоновую команду (сфокусированный блок
                или последний; `:kill all` останавливает все). SIGTERM, затем SIGKILL.
  :watch <sec> <command> - Перезапускать <command> каждые <sec> секунд в одном блоке
                (монитор как `watch -n`; тики заменяют текст, а не накапливаются)
                Остановка: :watch stop, F4 / :kill, :c или выход. Одновременно один watch.
  :mv <tag>[<tid>] <dst> - Перенести одну команду в другой тег (новый tid в конце)
  :mv <tag> <dst>   - Переименовать весь тег (комментарий тоже переносится)
  :stats            - Сводка использования библиотеки: запуски по тегам, топ-10
                команд, счётчик ни разу не запускавшихся. `!tag` сортирует по использованию.
  :/text  :g  - Поиск по строкам журнала; :n / n — след., :N / N — пред. / на блоке включает :/
  :export tag [file] - Записать один тег в JSON
  :export * [file.md] - Записать всю библиотеку как Markdown-каталог
                (с группировкой по тегам; комментарии тегов и команд включены)
  :diff         - Унифицированный diff stdout сфокусированного блока с предыдущим
                CommandBlock (без фокуса: два последних блока)
  :alias <tag> [file.sh] / :alias * [library.sh] - экспорт команд как
                bash-функций tag_tid() { ...; }
  :llm [provider] <message> - Спросить LLM (провайдеры из llm_providers.yml, `ask`,
                `offline`, `@file`, контекст; Tab — имена) — полностью: :? llm
  :cht <query>  - Шпаргалки cheat.sh в журнале (`:cht tar`; опции) — :? llm
  :o [N]        - Последние N завершённых выводов команд этой сессии (по умолчанию 5)
  :o /text      - grep по сохранённым выводам (stdout/stderr); переживает :c
  :o clear      - Забыть сохранённые выводы (только память, не БД)
  :kctx [cluster] [N] - Журнал кластеров: вход и сохранённые наборы переменных (:? kctx)
  :import <файл|url> - Вставить команды из JSON-файла (новые tid) или забрать
                общую библиотеку по https:// — сначала план изменений, потом
                `--yes`; `--dry`, `--insecure`, `library_url` — полностью: :? import
  :theme [name] - Показать или задать тему TUI (сохраняется в settings.yml)
               `matrix` — собственная тема приложения: зелёный фосфор на почти
               чёрном (как скринсэйвер); её рамки тоже становятся зелёными.
  :lang [code] - Показать или задать язык интерфейса (en, ru, …; `auto` следует $LANG).
               Сохраняется в settings.yml (ключ `language`); напечатанный после
               переключения текст использует его. При запуске: --lang / $IDVJPY_LANG.
               Команды, имена тегов и ключи настроек не переводятся.
  :relang [code] - Перевести комментарии засеянной библиотеки (подписи тегов и
               подсказки команд) в БД. Трогает только канонические теги и команды
               сидов: ваши теги, команды и правленые комментарии остаются как есть.
               Перед записью — снимок БД в backups/.
  :playbook [file] - Записать команды этой сессии как --demo YAML (по умолчанию playbook.yml)
  :playbook - / clear - Предпросмотр YAML в журнале / забыть записанные строки
  :run <tag|file.yml> - Запустить цепочку команд (runbook): шаги auto выполняются
                и ожидаются, `manual` ждёт вашего Enter (строка помещается во ввод
                для правки), `prompt` ждёт набранную вами строку. Сбой шага
                останавливает цепочку; Esc тоже останавливает. `--step` — каждый
                шаг ждёт (пошагово), `--dry` — только показать план, `:run stop` —
                остановить, `:run` — использование + теги с директивами run: (см. :? run)
  :update     - Сравнить этот VERSION с GitHub main (webxed/IDvjPy)
                Прокси 407: задайте $PROXY_USER / $PROXY_PASS (и HTTPS_PROXY)

[bold]Команды Kubernetes (префикс :i)[/bold]
  :i list             - Список всех ingress
  :i list -n <ns>     - Список ingress в namespace
  :i ns <namespace>   - Описать namespace (JSON-просмотрщик)

[bold]Префиксы команд[/bold]
  (нет)      - Выполнить shell-команду
               Строка, начинающаяся с цифры (или '(' / '-'), сначала пробуется как
               локальный калькулятор:
               512Mi + 20% in Gi    (увеличить память на 20% → = 0.6Gi)
               20% of 512Mi · 1/3 of 1Gi · 512Mi*30 in Gi · 1Gi/512Mi
               500m in cores · 2^10 · 524288 in Mi · (512+512)*2
               Единицы: B, KB/MB/GB/TB (×1000), KiB/MiB/GiB/TiB (×1024), k8s Ki/Mi/Gi, m.
               И IPv4-сети (как jodies.de/ipcalc): 192.168.1.0/24,
               10.1.2.3/255.255.255.0 или просто 8.8.8.8 (маска класса по умолчанию).
               Префикс для N хостов: 300 hosts → /23.
               Только когда вся строка разбирается как математика/единицы — иначе
               shell (7z …, (cd …), 2>/dev/null …).
               Полный справочник калькулятора: введите `:? calc`.
  > <cmd>    - Приостановить TUI и запустить с настоящим TTY (htop, vim, ssh, less)
               После выхода: импортировать export/unset того shell и $PWD; ещё :env
               Интерактивный ввод — здесь: фоновая команда получает /dev/null как
               stdin, поэтому не может читать клавиатуру/мышь TUI
  @ <cmd>    - Запуск без command_timeout (долгие не-TTY задачи; stdout захватывается,
               stdin — /dev/null). Сообщение о таймауте тоже указывает сюда и на `> cmd`
  Вывод      - ANSI-цвета команды рисуются как цвета (ansi_colors: true);
               escape-коды курсора/OSC и управляющие символы снимаются, прогресс
               перерисовки схлопывается в последнюю строку — как в настоящем
               терминале. Простой текст (F3, |, $OUT/$BLOCK, :log, @key) никогда
               не содержит escape-кодов
  #<tag>     - Сохранить команду в базу с тегом (`#tag cmd`, без пробела после #)
  # command  - Отложить строку в историю без выполнения (в стиле bash; пробел после #)
  #tag! / #tag!tid - Восстановить мягко удалённый тег / команду
  #name-- / #name!! - Скрыть / вернуть теги справочника (ansible, linux, k8s, …)
  ?          - Запрос к базе (? теги, ?<tag>, ?? с группировкой, ?text — поиск) — :? tags
  !tag / !tag[tid] - Подставить команду из базы в ввод (Tab выбирает) — :? tags
  !N         - Выполнить команду по ID из последнего запроса (:? tags)
  |<cmd>     - Направить вывод сфокусированного (иначе последнего) блока в команду
  |@<label> <cmd> - Направить из блока с меткой `:name <label>`
  |@N <cmd>  - Направить из N блоков назад (0 = последний). Источник НЕ перезапускается;
               история хранит полный вызов `<source> | <cmd>` для ↑/:h.
  :name [<label>|-] - Пометить сфокусированный/последний завершённый блок (без арг.:
               список; `<label>-`: убрать одну; `-`: убрать все). F8 открывает диалог
               для метки. Затем дёшево переиспользуйте его буфер: `:name buff` …
               `|@buff awk '{...}'` (без перезапуска cat/kubectl).
  $OUT       - Последняя непустая строка сфокусированного/последнего блока (:? vars)
  $VAR=val / $VAR=@key - Задать переменную (в т.ч. из вывода блока) (:? vars)
  $$VAR=val  - Секретная переменная: secrets_<instance>.json, 0600 (:? vars)
  алиасы     - Из ~/.bashrc; аргументы по правилам алиасов (:? vars)

[bold]Темы справки (:? <тема>)[/bold]
  :? calc    - Калькулятор и ipcalc: синтаксис, единицы, проценты, IPv4-подсети
  :? run     - Цепочки команд (runbook): шаги auto/manual/prompt, YAML, :playbook
  :? i       - Kubernetes Ingress Analyzer: list / ns / analyze / check
  :? md      - Markdown-справочники (`:md`) и поиск по ним (`:rg`)
  :? llm     - LLM-провайдеры (`:llm …`, `:llm ask`), файлы во вложении, :cht
  :? tags    - Запросы к базе: `?`, `?tag`, `??`, `?text` и ссылки `!tag[tid]`
  :? vars    - `$OUT`, `$VAR`, секреты `$$`, алиасы из ~/.bashrc
  :? kctx    - Журнал кластеров: вход и сохранённые наборы переменных
  :? send    - Пересылка команд в другую сессию (`:send` / `:send!`)
  :? session - Экземпляры приложения и окна (`:session`, `:new`)
  :? import  - JSON / общая библиотека по URL (`:import`, `:export`, `:backup`)
  :? mcp     - Библиотека тегов для AI-клиентов: `mcp_server.py` (MCP, только чтение)

[bold]Навигация[/bold]
  ↑/↓        - Перелистывание истории ввода: всё, что набрано в этой сессии
               (`:`-команды, `?теги`, `!ссылки`, `#теги`, `$VAR=…` — кроме
               `$$секретов`), затем отфильтрованный файл history_<instance>.txt;
               набранный текст фильтрует совпадения (без учёта регистра); при
               фокусе блока — скролл журнала
  Tab        - Сфокусировать последний блок журнала (из ввода), включая :h / :?
  Клик       - Сфокусировать блок журнала, не прыгая к его началу
               (нужен terminal_mouse: true в settings.yml)
  PgUp/PgDn  - Пролистать журнал на страницу; видимый блок становится активным
               (не прыгает к началу блока). Из ввода: вход в режим просмотра.
  Чтение     - Как только вы пролистали вверх (или блок журнала в фокусе), новый
               вывод добавляется снизу, НЕ двигая вид и не забирая фокус. Слежение
               возобновляется, когда вы прокрутите к концу или выполните команду
  Esc        - Вернуться ко вводу (см. также режим построчного курсора)
  Space      - Свернуть/развернуть блок
  ← / →      - Свернуть / развернуть сфокусированный блок
  F3         - Скопировать полный вывод блока в буфер обмена
  F4         - Остановить выполняющуюся фоновую команду (как :kill; группа SIGTERM)
  Ctrl+C     - Скопировать всю строку ввода; если блок журнала в фокусе — скопировать блок (как F3)
  F5         - Открыть сфокусированный (или последний) блок в JSON-просмотрщике
  F6         - Переключить простой (plain) вывод (Rich-разметка и ANSI-цвета
               выключены; escape-последовательности снимаются с любого вывода команды в обоих режимах)
  F7         - Полный вывод блока в Line-API просмотрщике (`:log`): поиск `/`, n/N,
               f — только совпавшие строки
  F8         - Диалог метки блока (`:name`): введите метку, Enter сохраняет, пустая
               удаляет, Esc отменяет. Затем `|@<label> <command>` переиспользует вывод без перезапуска.
  F2         - Переключить режим построчного курсора (см. ниже)
  Ctrl+O     - Показать консоль под TUI (как Midnight Commander): приложение
               отступает, чтобы вы прочитали настоящий терминал — вывод `> cmd`
               (htop/vim/less) живёт там, в прокрутке. Любая клавиша возвращает.
  Shift+Insert / Ctrl+V - Вставить во ввод (не заменяет существующий текст)
               В режиме построчного курсора Ctrl+V вместо этого добавляет текущую строку
               Переносы строк становятся пробелами (поле в одну строку); длинная
               строка целиком видна в сером превью сразу под полем
  Правый клик - Вставить во ввод, где бы ни был фокус: в журнале или в списке
               подсказок курсор переводить не нужно, и фокус не прыгает. Ссылки
               (--seed, .md, :команды) правым кликом не выполняются, и выделение
               он не затирает: выделенное мышью копируется при отпускании, и
               правый клик вставляет именно это
  Ctrl+D     - Очистить всю строку ввода
  (k8s) kubectl get <res> <Tab> - живые имена ресурсов кластера (k8s_completion: true)
  (пути) ./ | / | ~/ <Tab> - подсказки файлов/каталогов; голые имена после команд,
               принимающих файл (cat/vim/…), и со 2-го аргумента grep/sed/awk/jq.
               Считается по каждому сегменту команды: `cat f | grep ot` ничего не показывает.
               Подсказки описывают ПОСЛЕДНИЙ токен, поэтому пока курсор в другом
               слове, они не показываются и не применяются (правка имени команды
               в `bar ~/f.txt` больше не вставляет путь дважды).
               file_completion: auto | paths | off
  (ист) ↺ history <Tab> - строки истории, совпадающие с набранным, включая `@`/`>`
               команды (history_completion: true; :h /text тоже фильтрует).
               Полные команды из БД и истории заменяют ВСЮ строку, поэтому и
               показываются, и применяются только в конце строки: правка в
               середине никогда не затирается подсказкой.
  (JSON) Enter - Вставить `jq 'path'` во ввод; также задаёт $JSON

[bold]Режим построчного курсора[/bold]
  Сфокусируйте блок (Tab или PgUp), затем Enter или F2, чтобы включить режим.
  По умолчанию выключен: ↑/↓ по-прежнему прокручивают журнал.
  Включён: текущая строка подсвечена.
  ↑/↓        - Перемещение по строкам внутри блока
  Home/End   - Первая / последняя строка блока
  Enter      - Скопировать текущую строку (концевые пробелы сняты) и перейти ко вводу
               Ведущий `# ` (отложенная строка истории) убирается, чтобы команда была
               готова. Курсор идёт в конец ввода; существующий текст не выделяется
  Shift+Enter / Ctrl+V - Добавить текущую строку во ввод через пробел
               Ведущий `# ` снимается так же
               Остаётесь в блоке (можно добавить несколько строк)
               Если Shift+Enter ведёт себя как Enter, терминал не различает
               клавиши — используйте Ctrl+V. Пока ввод в фокусе, Ctrl+V вставляет
  Esc        - Выключить режим, остаться на блоке; Esc ещё раз возвращает ко вводу
  F2         - Переключить режим вкл/выкл
  /          - Начать поиск по журналу (:/ во вводе)
  n / N      - Следующее / предыдущее совпадение (прыгает к совпавшей строке)

[bold]Переменные[/bold]
  Используйте $VAR в командах для подстановки переменных
  $NS задаётся автоматически при использовании -n в командах :i
  $JSON задаётся по Enter в JSON-просмотрщике (jq-путь выбранного узла)
  $DBFILE — файл библиотеки SQLite, который открыло приложение (значение в .bashrc_term важнее)
  Пример: jq $JSON test.json
  $OUT — последняя строка сфокусированного/последнего блока команды, вычисляется
  только когда команда содержит $OUT / ${OUT} (не хранится в памяти как переменная)
  $VAR также загружается из .bashrc_term и .bashrc_term_<instance>
  :env перечитывает эти файлы. После `> cmd` экспорты из того же bash
  импортируются (вложенный `> bash`, затем export внутри — нет: только тот же shell).
  Экспорты TTY остаются в этой сессии; `$VAR=val` всё равно пишет в .bashrc_term_*

[bold]Режим демо[/bold]
  python3 app.py --demo              - Проиграть встроенный короткий тур (Esc останавливает)
  python3 app.py --demo full --demo-quit
  python3 app.py --demo path.yml --demo-speed 1.5
  YAML сценария: src/demos/*.yml (type / keys / wait_command / loop). Ручной сценарий: DEMO.md
  loop: true / loop: N  - Повторять шаги (вечно или N раз). Esc останавливает. Также шаг: loop: 10
  :playbook [file.yml]  - Выгрузить набранные в этой сессии строки как YAML; --demo этим файлом
  :playbook -           - Предпросмотр в журнале.  :playbook clear — сбросить журнал
  Клавиши (Tab/F5) и мышь не записываются; правьте YAML, если туру они нужны.

[bold]Справочники (пустая база)[/bold]
  Первый запуск без команд перечисляет в журнале скрипты сидов.
  python3 src/seed_linux_commands.py --seed
  python3 src/seed_k8s_chains.py --seed    # K8S_CHAINS.md — цепочки расследования
  python3 src/seed_git.py --seed
  python3 src/seed_ops.py --seed           # все ops, кроме linux / k8s / git
  Введите команду здесь, затем ?? (или подождите ~5с). Каждый --seed заменяет только свои теги.
  Рабочая БД сначала копируется в backups/; :backup делает тот же снимок вручную.
