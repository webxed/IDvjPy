[bold]:? md — markdown-справочники и поиск по ним[/bold]

  :md <file|path>[#L<n>] - Открыть markdown с форматированием: имя справочника
                репозитория или явный путь (например, файл из хранилища Obsidian);
                `#L<n>` открывает на исходной строке n (как GitHub). Esc закрывает.
                Записывается в историю (↑ / `:h`). `y` копирует полный путь (в
                форматированном виде также клик по имени в заголовке). Файлы больше
                `md_render_lines` (по умолчанию 1000) открываются как исходник в
                Line-API просмотрщике (быстро; поиск `/`, `n`/`N`) —
                форматированный виджет на больших файлах занимает десятки секунд
  :rg <pat> [dir] - Поиск regex в markdown-файлах (ripgrep или встроенный
                сканер с подсказкой об установке). Smart case; результаты —
                кликабельные фрагменты `path:line` — открываются в md-просмотрщике
                на этой строке; `:rg <N>` открывает результат N (с 1). База:
                [dir] → настройка `md_dir` → cwd. `:rg` / `:md` записываются
                в историю (↑ / `:h`)
  Настройки: `md_dir` (база поиска) и `md_render_lines` в settings.yml.
