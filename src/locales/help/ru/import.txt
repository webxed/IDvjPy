[bold]:? import — перенос библиотеки: JSON, ссылка, Markdown[/bold]

  :export <tag> [file] - Записать один тег в JSON; первый путь — файл назначения
                (`:export kube kube.json`)
  :export * [file] - Вся библиотека: `.json` — канонический JSON всей библиотеки
                (файл для общей ссылки `library_url`; то же, что `backup_db.py
                export` без `--tag`), иначе — Markdown-каталог (с группировкой
                по тегам; комментарии тегов и команд включены). По умолчанию — `library.md`
  :import <file.json> - Вставить команды из этого JSON. Один тег → [bold]новые[/bold] tid
                (ничего не затирается); файл всей библиотеки → обновление: занятая
                пара (тег, tid) пропускается (`skip_existing`)
  :import [--dry] [--yes] [--insecure] <https://…> - Загрузить общую библиотеку.
                Только https; `--insecure` разрешает обычный http:// (содержимое
                едет прямо в библиотеку — не для недоверенного хоста). Лимит 2 МБ,
                таймаут 10 с; прокси с логином — `$PROXY_USER` / `$PROXY_PASS`
                (слой общий с `:update` и `:llm`)
  :import - Без аргумента берётся статичная ссылка `library_url` из settings.yml
                (пусто — выключено: тогда нужен явный файл или ссылка)

  Внешний импорт не пишет молча: сначала в журнале план изменений, а во ввод
  подставляется готовая строка `:import <url> --yes` — Enter её импортирует
  (без второго Enter в библиотеку ничего не попадает). `--dry` показывает только
  план. Payload со значением живого `$$`-секрета отклоняется (`:? vars`).

  Что смотреть в плане:
    - «N step(s) run without confirmation in :run» — в файле есть директивы
      `run:auto` (`run:pause=…`): `:run <тег>` выполнит эти шаги сам
    - «skip N» — эти строки уже есть в библиотеке и не перезаписываются

  JSON — та же схема, что у CLI (`src/db_transfer.py`). `backup_db.py` — отдельный
  лаунчер в каталоге репозитория: из каталога данных запускайте его по пути
  (`python3 /path/to/IDvjPy/backup_db.py export library.json`) — голое
  `python3 backup_db.py …` работает только из репозитория. Файл ложится в его
  `backups/`; точный слепок — снимок SQLite (`:backup`), не JSON.
  Плюс адресный CSV по паре (тег, tid). Подробности — backup_db.md.
