[bold]:? snapshot — bounded output snapshots[/bold]

  :snapshot list          List saved snapshots
  :snapshot save NAME     Save stdout from the focused command block, or the latest block
  :snapshot show NAME     Display the saved stdout
  :snapshot diff NAME     Compare saved stdout with the focused/latest command block
  :snapshot rm NAME       Remove a snapshot

  Snapshots are stored in output_snapshots.json in the application data directory,
  separately from the SQLite tag library and command history. The file is private
  (0600), atomically replaced, and capped at 5 MiB; at most 20 snapshots are kept,
  each at most 256 KiB. Saving an existing name replaces that snapshot.

  Only stdout is stored. It is secret-masked at save time; stderr, command text,
  environment variables and vault contents are never included. Oversized stdout is
  truncated on a UTF-8 boundary. This is a local comparison aid, not an audit log
  or a backup of command output.

  `:diff` remains available to compare two blocks currently in the journal.
