[bold]:? vars — 变量、块输出与别名[/bold]

  $OUT       - 按需：聚焦（或最后一个）命令块的最后一行非空内容。
               不保存在 .bashrc_term 中。单独输入 $OUT
               可以查看它。`$OUT=` 被拒绝。
  $VAR=val   - 设置环境变量
  $VAR=@key  - 从聚焦/最后一个已完成的块中取值：
               取第一个 token 为 `key` 的行（vault 表格 `key  value`）；
               `@last` — 最后一行。配合 `$$` 保存密钥：`$$VAULT_TOKEN=@token`。
  $$VAR=val  - 设置密钥变量：值在输入行和
               日志中隐藏（显示为 ****）；保存在 secrets_<instance>.json (0600)，
               退出时删除（仅会话）；绝不发送给 :llm
               （会掩码为 ****）。像 $VAR 一样使用。`$$VAR` — 状态，
               `$$VAR-` — 删除。整个输入行会被掩码（名称可见于
               副标题）；在真正的 TTY 中，`> cmd` 的值可见；F3 复制
               真实输出。设置键 `clear_clipboard_after_secret: true`
               会在值插入 `$$NAME=…` 后清空剪贴板。
  $DBFILE    - 由应用设置：它打开的 SQLite 库文件路径（`sqlite` 手册用它工作）。
               .bashrc_term 中的值优先。
  别名       - 来自 ~/.bashrc。如果函数体中有 $1 / $2 / $@，参数会被代入
               （klogin cluster → tsh kube login cluster）。否则行的剩余部分
               会像经典别名那样追加。参数在
               第一个 shell 操作符处结束：`klogin prod || kubectl config use-context prod`
               会让 `||` 保持为操作符（它不会成为别名函数体的参数）。
