[bold]IDvjPy_term VER - 命令帮助[/bold]

[bold]应用命令（前缀 :）[/bold]
  输入 `:` 查看所有命令的列表及单行提示
  （字母过滤列表，Tab/Enter 插入命令；再按一次 Enter 执行）。
  点击下面的名称会把调用插入输入框 — 不会运行任何东西。
  `:/text` — 在日志中搜索。
  命令组由主题详细讲解 — `:? <主题>`（列表见「帮助主题」）。
  :? [topic]   - 显示本帮助；`:? llm`、`:? tags`、`:? calc` … — 完整讲解该主题
  :q          - 退出应用
  :w <file>   - 将输出写入文件
  :h [N]      - history_<instance>.txt 的最后 N 行（默认：20）
                查询类命令的调用（`:llm`、`:cht`、`:rg`、`:md`、`:run`、
                `:send`）会留在那里供 ↑/`:h` 使用，但绝不会被提示 —
                列表为 settings.yml 中的 `history_queries`（留空 — 不记录）。
                拼写错误（`command not found`，127）会从文件和 ↑ 中移除 —
                `history_forget_not_found: false` 会保留它
  :h /text    - 在该文件的提示中搜索（唯一行，新的在上）；Enter 输出块
  :h compact  - 去重的旧历史；最后 history_keep 行保持为序列
  :h import [shell] - 追加你的 shell 历史（bash/zsh/fish/ksh/nu/pwsh；`$HISTFILE`
                优先；Linux/macOS/Windows 的路径）到 history_<instance>.txt —— ↑、
                `:h /text` 和提示会立即看到它们。每个文件取最后 5000 行；
                不会执行任何内容。不带名称 —— 所有找到的 shell。
  :c          - 清空所有输出块
  :json       - 打开 JSON 查看器（来自最后一个块）
  :json <file>- 在查看器中打开 JSON 文件
  :md <file|path>[#L<n>] - 以格式化方式打开的 markdown 手册，`#L<n>` — 源文件第 n 行（:? md）
  :rg <pat> [dir] - 按 regex 搜索 markdown 文件，结果可点击（:? md）
  :i          - Kubernetes Ingress 分析器（:i — 命令，:? i — 详细）
  :cd [path]  - 显示或更改 shell 的 cwd（标签数据库 / 历史仍留在启动目录）
  :fm [path]  - 在新窗口中打开系统文件管理器（cwd 或 path）
  :term [path] - 在新窗口中打开系统终端（cwd 或 path）
                $FILEMAN / $TERMINAL 覆盖系统默认值
  :ed [<file>|$OUT|$BLOCK] - 在外部编辑器中打开文件（或块的最后一行 / 完整
                stdout / 空缓冲区）；TUI 在运行期间
                暂停。编辑器：settings.yml 中的 `editor:`，否则
                $VISUAL / $EDITOR，否则 sensible-editor / nano / vi。磁盘上的
                文件就地修改。对于 $OUT/$BLOCK/空缓冲区：
                单行结果会进入输入框（Enter 执行它）；
                多行会按打印出的临时路径保存
                （适用于 `@file` / `| cmd`）。`$VAR` 和惰性 `$OUT`
                会代入路径（例如 `:ed $TMPDIR/pod-$OUT.json`）；
                未解析的 `$NAME` — 明确报错，而不是名为 `$NAME` 的文件。
  :env        - 将 .bashrc_term*（以及 ~/.bashrc 别名）重新读入本进程
  :session    - 显示或切换应用实例（标签数据库共享；:? session）
  :new [NAME|-] [DIR] - 在新的终端窗口中打开另一个应用实例（Ctrl+N；:? session）
  :send <session|*> <cmd> - 将命令转发到另一个会话（`:send!` — 立即；
                密钥按名称传递，值写入目标自己的存储；:? send）
  :scope [add|rm|clear] … - 本窗口的标签范围：`:scope add git` 只列出 git 手册，
                `:scope rm k8s` 将其隐藏，`:scope clear`（或 `:scope all`）重新
                显示全部。只过滤列表与提示（`?`、`??`、`?text`、`!`/Tab 补全、
                屏保滚动条）；显式引用（`?tag`、`!tag[tid]`、`:run`、`:stats`、
                `:export`）照常工作，已保存的链条不会被破坏。名称可以是手册组
                （linux、k8s、git …）或单个标签。按会话保存：scope_<会话>.json；
                窗口标题带有标记（`IDvjPy_term · git · only git`）。详见 :? tags
  :welcome      - 种子目录（如同空数据库时的欢迎语；点击 --seed / .md）
  :backup       - 将命令数据库复制到 backups/（与 --seed 相同的快照）
  :screensaver  - 空闲覆盖层：矩阵数字雨（screensaver_matrix，
                默认）或 NC 风格的星空；整宽滚动条；
                左下角帮助；右下角 load/mem。`:screensaver matrix`
                / `:screensaver stars` 单次选择画布；`:screensaver 0` /
                `120` 设置空闲秒数（screensaver_idle）；按键/点击/
                滚动/鼠标移动会重置它，转发的 :send 会唤醒它，
                而有真正 TTY 的会话（`> cmd`、Ctrl+O、`:ed`）会重新开始
                空闲计时 — 返回时不会遇到覆盖层
  :r          - 将聚焦（或最后一个）块的命令放入输入框
  :r N        - 将往前第 N 个块的命令放入输入框（0 = 最后一个）
  :cmd [N] [show] - 用当前 $VAR 值（包括密钥）具体化块的命令
                并复制到剪贴板；`show` 还会
                打印它（密钥会变为可见）。N = 往前第几个块（0 = 最后一个）。
  :log [N]    - 在可滚动的 Line-API 查看器中查看块的完整输出（不限
                300 行；行 —— ↑/↓，翻页 —— PgUp/PgDn，Esc 或 q
                关闭）。通过 `/` 搜索；Enter — 搜索，n/N — 下一个/
                上一个匹配，Esc — 关闭搜索框。匹配的行
                整行高亮（强调背景 + bold）。`f` — 仅显示匹配的
                行（再按 `f` / Esc — 返回所有行；需要
                先搜索；副标题保留原始行号
                ），此时用方向键 ↑/↓ 在匹配之间移动（而不是滚动）。
                Enter / Ctrl+C 把选中的（高亮的）行复制到剪贴板
                （如同 F2 逐行模式中的 Enter；没有搜索时无选中项 ——
                查看器会明确说明，而不是复制第一行）。
                N = 往前第几个块（0 = 聚焦/最后一个）。
                显示块的 stdout（同 F3），转义码会被去除。也有
                F7。`y` 复制源文件路径（`:md` 的原始视图）
  :kill [all] - 停止正在运行的后台命令（聚焦的块
                或最后一个；`:kill all` 停止所有）。SIGTERM，然后 SIGKILL。
  :watch <sec> <command> - 在一个块中每 <sec> 秒重新运行 <command>
                （类似 `watch -n` 的监视器；每次刷新替换文本而非累积）
                停止：:watch stop、F4 / :kill、:c 或退出。同时只能有一个 watch。
  :mv <tag>[<tid>] <dst> - 将一条命令移到另一个标签（新 tid 在末尾）
  :mv <tag> <dst>   - 重命名整个标签（注释也会一起转移）
  :stats            - 库使用统计：按标签的运行次数、前 10
                命令、从未运行过的计数。`!tag` 按使用情况排序。
  :/text  :g  - 在日志行中搜索；:n / n — 下一个，:N / N — 上一个 / 在块上启用 :/
  :export tag [file] - 将一个标签写入 JSON
  :export * [file.md] - 将整个库写为 Markdown 目录
                （按标签分组；包含标签和命令的注释）
  :diff         - 聚焦块的 stdout 与上一个 CommandBlock 的统一 diff
                （无聚焦时：最后两个块）
  :alias <tag> [file.sh] / :alias * [library.sh] - 将命令导出为
                bash 函数 tag_tid() { ...; }
  :llm [provider] <message> - 询问 LLM（提供方来自 llm_providers.yml，`ask`、
                `offline`、`@file`、上下文；Tab — 名称）— 详见 :? llm
  :cht <query>  - 日志中的 cheat.sh 速查表（`:cht tar`；选项）— :? llm
  :o [N]        - 本会话最近 N 个已完成的命令输出（默认 5）
  :o /text      - 在保存的输出（stdout/stderr）中 grep；能挺过 :c
  :o clear      - 忘记保存的输出（仅内存，非数据库）
  :kctx [cluster] [N] - 集群日志：登录与已保存的变量集合（:? kctx）
  :import <文件|url> - 从 JSON 文件插入命令（新 tid），或通过 https:// 获取
                共享库 — 先显示变更计划，再用 `--yes` 确认；`--dry`、
                `--insecure`、`library_url` — 详见 :? import
  :theme [name] - 显示或设置 TUI 主题（保存在 settings.yml 中）
               `matrix` — 应用自带主题：近乎黑色上的绿色荧光
               （如同屏保）；它的边框也会变绿。
  :lang [code] - 显示或设置界面语言（en、ru、…；`auto` 跟随 $LANG）。
               保存在 settings.yml 中（键 `language`）；切换后打印的
               文本会使用它。启动时：--lang / $IDVJPY_LANG。
               命令、标签名和设置键不会被翻译。
  :relang [code] - 将已播种库的注释（标签说明和
               命令提示）翻译到数据库中。只触及规范的标签和
               种子命令：你自己的标签、命令和手改过的注释保持原样。
               写入前 — 将数据库快照保存到 backups/。
  :playbook [file] - 将本会话的命令记录为 --demo YAML（默认 playbook.yml）
  :playbook - / clear - 在日志中预览 YAML / 忘记已记录的行
  :run <tag|file.yml> - 运行命令链（运行手册）：auto 步骤会执行
                并等待完成，`manual` 等待你的 Enter（该行会放入输入框
                供编辑），`prompt` 等待你输入的行。某步失败
                会停止链条；Esc 也会停止。`--step` — 每一步
                都等待（逐步），`--dry` — 只显示计划，`:run stop` —
                停止，`:run` — 用法 + 带 run: 指令的标签（见 :? run）
  :update     - 将此 VERSION 与 GitHub main (webxed/IDvjPy) 比较
                代理 407：设置 $PROXY_USER / $PROXY_PASS（以及 HTTPS_PROXY）

[bold]Kubernetes 命令（前缀 :i）[/bold]
  :i list             - 列出所有 ingress
  :i list -n <ns>     - 列出 namespace 中的 ingress
  :i ns <namespace>   - 描述 namespace（JSON 查看器）

[bold]命令前缀[/bold]
  (无)      - 执行 shell 命令
               以数字（或 '(' / '-'）开头的行会先被当作
               本地计算器尝试：
               512Mi + 20% in Gi    （将内存增加 20% → = 0.6Gi）
               20% of 512Mi · 1/3 of 1Gi · 512Mi*30 in Gi · 1Gi/512Mi
               500m in cores · 2^10 · 524288 in Mi · (512+512)*2
               单位：B、KB/MB/GB/TB（×1000）、KiB/MiB/GiB/TiB（×1024）、k8s Ki/Mi/Gi、m。
               以及 IPv4 网络（如同 jodies.de/ipcalc）：192.168.1.0/24、
               10.1.2.3/255.255.255.0 或直接 8.8.8.8（默认类掩码）。
               N 台主机的前缀：300 hosts → /23。
               仅当整行都能解析为数学/单位时 — 否则交给
               shell（7z …、(cd …)、2>/dev/null …）。
               完整计算器参考：输入 `:? calc`。
  > <cmd>    - 暂停 TUI 并以真正的 TTY 运行（htop、vim、ssh、less）
               退出后：导入该 shell 的 export/unset 和 $PWD；还有 :env
               交互式输入 — 在这里：后台命令以 /dev/null 作为
               stdin，因此无法读取 TUI 的键盘/鼠标
  @ <cmd>    - 在无 command_timeout 下运行（长时间的非 TTY 任务；stdout 会被捕获，
               stdin — /dev/null）。超时消息也会指向这里和 `> cmd`
  输出      - 命令的 ANSI 颜色会按颜色渲染（ansi_colors: true）；
               光标/OSC 转义码和控制字符会被去除，进度
               重绘会折叠到最后一行 — 如同真正的终端。纯
               文本（F3、|、$OUT/$BLOCK、:log、@key）绝不包含转义码
  #<tag>     - 将命令以标签保存到数据库（`#tag cmd`，`#` 后无空格）
  # command  - 将该行暂存到历史而不执行（bash 风格；`#` 后有空格）
  #tag! / #tag!tid - 恢复被软删除的标签 / 命令
  #name-- / #name!! - 隐藏 / 恢复手册标签（ansible、linux、k8s、…）
  ?          - 查询数据库（? 标签、?<tag>、?? 分组、?text — 搜索）— :? tags
  !tag / !tag[tid] - 将数据库命令插入输入框（Tab 选择）— :? tags
  !N         - 按上次查询中的 ID 执行命令（:? tags）
  |<cmd>     - 将聚焦（否则最后一个）块的输出管道到命令
  |@<label> <cmd> - 从带 `:name <label>` 标记的块管道
  |@N <cmd>  - 从往前第 N 个块管道（0 = 最后一个）。源不会重新运行；
               历史会为 ↑/:h 保存完整调用 `<source> | <cmd>`。
  :name [<label>|-] - 标记聚焦/最后一个已完成的块（无参数：
               列出；`<label>-`：移除一个；`-`：移除全部）。F8 打开
               标签对话框。之后可以低成本复用其缓冲区：`:name buff` …
               `|@buff awk '{...}'`（无需重新运行 cat/kubectl）。
  $OUT       - 聚焦/最后一个块的最后一行非空内容（:? vars）
  $VAR=val / $VAR=@key - 设置变量（也可取自块的输出）（:? vars）
  $$VAR=val  - 密钥变量：secrets_<instance>.json，0600（:? vars）
  别名       - 来自 ~/.bashrc；参数遵循别名规则（:? vars）

[bold]帮助主题 (:? <主题>)[/bold]
  :? calc    - 计算器 + ipcalc：语法、单位、百分比、IPv4 子网
  :? run     - 命令链（runbook）：auto/manual/prompt 步骤、YAML、:playbook
  :? i       - Kubernetes Ingress 分析器：list / ns / analyze / check
  :? md      - markdown 手册（`:md`）及其搜索（`:rg`）
  :? llm     - LLM 提供方（`:llm …`、`:llm ask`）、附件、:cht
  :? tags    - 数据库查询：`?`、`?tag`、`??`、`?text` 与 `!tag[tid]` 引用
  :? vars    - `$OUT`、`$VAR`、`$$` 密钥、~/.bashrc 别名
  :? kctx    - 集群日志：登录与已保存的变量集合
  :? send    - 将命令转发到另一个会话（`:send` / `:send!`）
  :? session - 应用实例与窗口（`:session`、`:new`）
  :? import  - JSON / 通过链接的共享库（`:import`、`:export`、`:backup`）

[bold]导航[/bold]
  ↑/↓        - 翻看输入历史：本会话中输入的一切
               （`:` 命令、`?标签`、`!引用`、`#标签`、`$VAR=…` — 除了
               `$$密钥`），然后是过滤后的 history_<instance>.txt 文件；
               已输入的文本会过滤匹配项（不区分大小写）；当
               块聚焦时 — 滚动日志
  Tab        - 聚焦日志的最后一个块（从输入框），包括 :h / :?
  点击       - 聚焦日志块，而不跳到它的开头
               （需要 settings.yml 中的 terminal_mouse: true）
  PgUp/PgDn  - 按页滚动日志；可见的块变为活动块
               （不会跳到块的开头）。从输入框：进入查看模式。
  阅读       - 一旦你向上滚动（或日志块处于聚焦），新的
               输出会从底部添加，不移动视图也不夺走焦点。当
               你滚到末尾或执行命令时，跟随会恢复
  Esc        - 返回输入框（另见逐行光标模式）
  Space      - 折叠/展开块
  ← / →      - 折叠 / 展开聚焦的块
  F3         - 将块的完整输出复制到剪贴板
  F4         - 停止正在运行的后台命令（如同 :kill；SIGTERM 组）
  Ctrl+C     - 复制整行输入；如果日志块处于聚焦 — 复制该块（如同 F3）
  F5         - 在 JSON 查看器中打开聚焦（或最后一个）块
  F6         - 切换纯（plain）输出（Rich 标记和 ANSI 颜色
               关闭；两种模式下任何命令输出的转义序列都会被去除）
  F7         - 在 Line-API 查看器中查看块的完整输出（`:log`）：搜索 `/`、n/N、
               f — 仅匹配的行
  F8         - 块标签对话框（`:name`）：输入标签，Enter 保存，留空
               则删除，Esc 取消。之后 `|@<label> <command>` 复用输出而无需重新运行。
  F2         - 切换逐行光标模式（见下文）
  Ctrl+O     - 显示 TUI 下方的控制台（如同 Midnight Commander）：应用
               会让开，让你阅读真正的终端 — `> cmd` 的输出
               （htop/vim/less）就活在它的回滚缓冲中。按任意键返回。
  Shift+Insert / Ctrl+V - 插入到输入框（不替换已有文本）
               在逐行光标模式下，Ctrl+V 则改为追加当前行
               换行会变成空格（输入框只有一行）；长行在输入框下方的
               灰色预览中完整可见
  右键点击  - 无论焦点在哪都将内容插入输入行：焦点在日志或提示列表中时，
               无需先把光标移到输入行，焦点也不会跳走。右键不会触发链接
               （--seed、.md、:命令），也不会覆盖选区：鼠标选中的文本在松开时
               已复制，右键粘贴的正是它
  Ctrl+D     - 清空整行输入
  (k8s) kubectl get <res> <Tab> - 集群资源的实时名称（k8s_completion: true）
  (路径) ./ | / | ~/ <Tab> - 文件/目录提示；在接收文件的命令
               （cat/vim/…）之后的裸名称，以及 grep/sed/awk/jq 的从第 2 个参数起。
               按命令的每个段单独计算：`cat f | grep ot` 不显示任何内容。
               提示描述的是最后一个标记，因此当光标位于其他单词时，
               它们既不显示也不会被应用（在 `bar ~/f.txt` 中修改命令名
               不会再插入两次路径）。
               file_completion: auto | paths | off
  (历史) ↺ history <Tab> - 与已输入内容匹配的历史行，包括 `@`/`>`
               命令（history_completion: true；:h /text 也会过滤）。
               来自数据库和历史的完整命令会替换整行，因此只在行尾显示
               和应用：行中间的修改永远不会被补全覆盖。
  (JSON) Enter - 将 `jq 'path'` 插入输入框；也会设置 $JSON

[bold]逐行光标模式[/bold]
  聚焦一个块（Tab 或 PgUp），然后按 Enter 或 F2 开启该模式。
  默认关闭：↑/↓ 仍然滚动日志。
  开启时：当前行会高亮。
  ↑/↓        - 在块内逐行移动
  Home/End   - 块的第一行 / 最后一行
  Enter      - 复制当前行（去除行尾空格）并转到输入框
               开头的 `# `（暂存的历史行）会被去掉，使命令
               就绪。光标移到输入框末尾；不会选中已有文本
  Shift+Enter / Ctrl+V - 用空格将当前行追加到输入框
               开头的 `# ` 同样会被去掉
               你会留在块中（可以追加多行）
               如果 Shift+Enter 的表现像 Enter，说明终端无法区分
               按键 — 请使用 Ctrl+V。当输入框聚焦时，Ctrl+V 会插入
  Esc        - 关闭模式，留在块上；再按 Esc 返回输入框
  F2         - 切换模式开/关
  /          - 开始在日志中搜索（输入框中的 :/）
  n / N      - 下一个 / 上一个匹配（跳到匹配的行）

[bold]变量[/bold]
  在命令中使用 $VAR 来代入变量
  $NS 在 :i 命令中使用 -n 时自动设置
  $JSON 在 JSON 查看器中按 Enter 时设置（所选节点的 jq 路径）
  示例：jq $JSON test.json
  $OUT — 聚焦/最后一个命令块的最后一行，仅当命令包含
  $OUT / ${OUT} 时才会计算（不会作为变量存在内存中）
  $VAR 也会从 .bashrc_term 和 .bashrc_term_<instance> 加载
  :env 会重新读取这些文件。在 `> cmd` 之后，同一个 bash 中的导出
  会被导入（嵌套的 `> bash` 然后在里面 export — 不会：只有同一个 shell）。
  TTY 的导出会留在本会话中；`$VAR=val` 仍会写入 .bashrc_term_*

[bold]演示模式[/bold]
  python3 app.py --demo              - 播放内置的短游览（Esc 停止）
  python3 app.py --demo full --demo-quit
  python3 app.py --demo path.yml --demo-speed 1.5
  场景 YAML：src/demos/*.yml（type / keys / wait_command / loop）。手动场景：DEMO.md
  loop: true / loop: N  - 重复步骤（永久或 N 次）。Esc 停止。也可在步骤中：loop: 10
  :playbook [file.yml]  - 将本会话中输入的行导出为 YAML；用 --demo 播放此文件
  :playbook -           - 在日志中预览。  :playbook clear — 重置日志
  按键（Tab/F5）和鼠标不会被记录；如果游览需要它们，请编辑 YAML。

[bold]手册（空数据库）[/bold]
  首次无命令启动时，会在日志中列出种子脚本。
  python3 src/seed_linux_commands.py --seed
  python3 src/seed_k8s_chains.py --seed    # K8S_CHAINS.md — 排查链
  python3 src/seed_git.py --seed
  python3 src/seed_ops.py --seed           # 所有 ops，除 linux / k8s / git

  工作数据库会先复制到 backups/；:backup 手动执行同样的快照。
