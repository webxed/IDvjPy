[bold]:? md — markdown 手册与搜索[/bold]

  :md <file|path>[#L<n>] - 以格式化方式打开 markdown：仓库手册名
                或显式路径（例如来自 Obsidian 仓库的文件）；
                `#L<n>` 打开到源文件第 n 行（类似 GitHub）。Esc 关闭。
                会记入历史（↑ / `:h`）。`y` 复制完整路径（在
                格式化视图中也可点击标题中的名称）。大于
                `md_render_lines`（默认 1000）的文件会作为源文件在
                Line-API 查看器中打开（快速；搜索 `/`、`n`/`N`）—
                格式化组件在大文件上要花数十秒
  :rg <pat> [dir] - 在 markdown 文件中搜索 regex（ripgrep 或内置
                扫描器，会提示安装）。Smart case；结果为
                可点击的 `path:line` 片段 — 在 md 查看器中打开
                到该行；`:rg <N>` 打开第 N 个结果（从 1 开始）。基准：
                [dir] → `md_dir` 设置 → cwd。`:rg` / `:md` 会记入
                历史（↑ / `:h`）
  :md notes.docx / report.pdf - 不是 markdown？`:md` 会转换它。转换器来自 settings.yml
                的 `md_converter`，否则用第一个找到的：anydoc → markitdown → pandoc。
                推荐 `pip install firecrawl-anydoc`（无依赖；docx/xlsx/pptx/doc/ppt/
                xls/pdf/rtf/epub/odt；PDF 本地解析）。转换结果缓存在数据目录的
                mdcache/，因此查看器里的 `#L<n>`、`/` 搜索和 `y` 与普通文件一样。
                没有转换器时给出安装提示；扫描版 PDF 需要 OCR（离线不支持）。
  设置：`md_dir`（搜索基准）、`md_render_lines` 和 `md_converter` 在 settings.yml 中。
