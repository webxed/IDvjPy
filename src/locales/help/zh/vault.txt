[bold]Vault —— 按密码加密的密钥保管库（`:vault`）[/bold]

  长期保存密钥，与 `$$NAME=…`（仅存活于本次会话）不同。文件是数据目录中的
  `vault.json.enc`（0600）：头部公开，条目已加密（scrypt + AES-256-GCM）。
  密码错误或文件损坏会给出明确错误，而不是显示乱码。

  每次会话解锁一次；密码只留在内存中：

    :vault init               创建保管库（密码需输入两次）
    :vault unlock | lock      本次会话解锁 / 忘记
    :vault                    文件、锁定状态、密钥名称（从不显示值）

  管理条目：

    :vault add NAME [hint]    添加或替换值；窗口中还有备注输入框
    :vault comment NAME [text]  只修改备注（值保持不变）；
                              `;` 分隔链接，不带文本则显示，`-` 清除
    :vault gen NAME [len]     生成随机值
    :vault list               名称与备注（每条链接单独一行）
    :vault rm NAME            删除条目

  取出值 —— 值从不打印：

    :vault cp NAME               → 剪贴板（离开 TTY 时以及 60 秒后清除）
    :vault use NAME [VAR]        → 本次会话环境中的 $VAR
    :vault exec NAME[=VAR] -- cmd    放入子进程 env，而非 argv
    :vault stdin NAME -- cmd         把值送入命令的 stdin
    :vault unuse [NAME|*]            移除已导出的变量（NAME，或 `*` 表示全部）

  `exec` 会为已知程序自动选择变量（sshpass → SSHPASS、psql → PGPASSWORD、
  mysql/mysqldump → MYSQL_PWD、vault → VAULT_TOKEN、restic、borg、redis-cli）；
  其他情况请显式写 `NAME=VAR`。程序本身必须已安装（如 `apt install sshpass`）——
  保管库只提供变量。sshpass 用 `-e`（从 `$SSHPASS` 读取），不要用 `-p`：`-p` 会把
  值放进 argv，`ps` 能看到。

  备注是每条记录的标注：密钥属于哪里、相关链接、提醒：
  `:vault comment SSH_PROD prod ssh;https://gitlab.example/proj;ssh://u@host`。
  它**不是**密钥，也不会被遮蔽：会按原样进入日志、`↑` 和 `history_*.txt` ——
  不要把值本身（或带 token 的 URL）写进备注。在 `cp`/`use` 的
  消息中备注会显示在名称旁边。

  规则：值不会进入日志、`:o`、`↑`、`history_*.txt`、`:send` 或 `:export`；
  解锁期间它们会像 `$$` 密钥一样被遮蔽，`use` 导出的变量也同样被遮蔽（即使
  保管库已上锁）。`cp` 是最薄弱环节 —— 其他程序可以读取剪贴板。需要
  `cryptography` 包（`pip install cryptography`）；没有它应用其余部分照常工作。

  [bold]TOTP 验证码：[/bold] 无需手机的两步验证码。密钥本身和其它条目一样加密
  保存；屏幕上只显示当前一次性验证码，密钥从不打印：

    :vault add GITHUB --totp      粘贴 base32 密钥或 otpauth:// 链接
    :vault totp GITHUB            实时验证码：每秒刷新，Enter/`c` 复制最新的码，
                                  Esc 关闭而不复制

  `--totp` 的值可以是裸 base32 密钥（`jbsw y3dp ehpk 3pxp`），也可以是二维码里的
  链接（`otpauth://totp/Issuer:acct?secret=…&issuer=…&digits=…`）：位数（6–8）、
  周期和算法（SHA1/256/512）按条目保存。验证码 **不是** 密钥：可以显示和复制
  （有效期 30 秒，可能进入日志和 `:o`，与密钥不同）。计数来自系统时钟，时钟不准
  验证码就不准。这里两个因素放在同一存储里 —— 用来随手保存验证码很方便，但不是
  信任别人密码的理由。

  [bold]自动锁定：[/bold] `vault_idle_lock` 分钟内没有任何保管库操作后自动上锁
  （默认 15）—— 忘记密码，下次读取会重新要求输入密码。`:vault use` 给出的
  变量会**留在**环境中（如需清除：`:vault unuse`）。`:vault autolock N` 修改本次
  会话的时长，`0` 关闭；settings.yml 中的 `vault_idle_lock: 0` —— 永久关闭。

  示例：`:vault init`、`:vault add SSH_PROD 生产 ssh`、`:vault cp SSH_PROD`
  再 `> ssh …`（粘贴），或者 `:vault exec SSH_PROD -- sshpass -e ssh user@host`
  （需要已安装 sshpass）。
