[bold]:? tags — 数据库查询与引用[/bold]

  ?          - 查询数据库（? 标签、?<tag>、?? 带分组；?? 显示隐藏标签）
               输入 `?` 会显示带提示的标签（命令数 + 标签注释）：
               字母过滤，Tab/Enter 插入 `?tag`（再按 Enter 执行），
               点击某行立即执行查询。`??` 保持原样。
               ?text（2 个及以上字符，且不是已有标签）= 在所有标签中
               搜索命令/注释；行：<id> tag[tid]；Esc → 输入框，然后 Enter 通过 !ID 执行
               在 ?? 中点击标签 → 将 `!tag ` / `!tag[tid] ` 插入光标位置
               （不替换整行；terminal_mouse）。Ctrl+点击或双击
               `!tag[tid]` 会插入并立即执行（就好比输入引用并
               按两次 Enter；不带 tid 的 `!tag ` 只会插入）。Esc → 输入框，
               然后 Enter。
  !tag / !tag[tid] - 输入 ! 以获得标签列表 [file, kube, log]；Tab 选择标签
               然后命令显示为 `<id> tag[tid]  完整命令`；Tab 插入 `!tag[tid]`
               组合管道/保存：`#file !file[1] | !file[2]`（预览会展开引用）
  !N         - 按上次查询中的 ID 执行命令
